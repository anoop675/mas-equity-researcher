# Autonomous Equity Research & Valuation Multi-Agent System

A multi-agent AI system that replicates the workflow of a Wall Street equity research associate, autonomously generating professional PDF investment reports for any publicly traded stock or cryptocurrency from a single natural language input.

---

## Project Structure

```
mas-equity-researcher/
├── agents/
│   ├── __init__.py
│   ├── ticker_resolver.py       # Validates and resolves natural language input to a ticker
│   ├── data_gathering.py        # Fetches financial statements and price data
│   ├── sentiment.py             # Scrapes and classifies news sentiment
│   ├── financial_analyst.py     # Runs the DCF valuation model
│   └── qa_reporter.py           # QA checks and generates the PDF report
├── tools/
│   ├── __init__.py
│   ├── yfinance_tool.py         # yfinance wrappers for financial data
│   ├── dcf_model.py             # 10-year DCF calculation logic
│   ├── vector_store.py          # Qdrant semantic search over SEC 10-K filings
│   └── pdf_generator.py         # ReportLab PDF generation
├── .env                         # Environment variables (not committed to git)
├── .env.example                 # Template showing required variables
├── .gitignore
├── config.py                    # Central config and environment variable loading
├── llm.py                       # LLM model configuration
├── orchestrator.py              # CrewAI crew and task definitions
├── main.py                      # Entry point
├── ingest_filings.py            # One-time script to seed Qdrant with SEC filings
├── Dockerfile
└── requirements.txt
```

## Agent Pipeline

```
User Input ("Analyze TSLA" / "Apple" / "bitcoin")
            │
   [Ticker Resolver Agent]
   Validates and resolves input to a ticker symbol
            │
   [Financial Data Agent]
   Fetches income statements, balance sheet,
   cash flow, price history, and 10-K risk factors
            │
   [Sentiment Agent]
   Scrapes Yahoo Finance, Google News, Seeking Alpha
   Classifies as Bullish / Neutral / Bearish
            │
   [DCF Analyst Agent]
   Computes WACC, projects 10-year FCF,
   derives intrinsic value per share
   Issues BUY / HOLD / SELL recommendation
            │
   [QA Reporter Agent]
   Validates consistency, generates PDF report
            │
   reports/TICKER_research_YYYY-MM-DD.pdf
```

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/anoop675/mas-equity-researcher.git
cd mas-equity-researcher
```

### 2. Create your environment file

```bash
cp .env.example .env
```

Open `.env` and fill in your values:

```bash
GROQ_API_KEY=gsk_your_groq_api_key_here
STOCK=TSLA
```

The `STOCK` variable sets which stock to analyse. You can use:
- A ticker symbol: `TSLA`, `AAPL`, `NVDA`
- A company name: `Apple`, `Nvidia`
- A description: `the EV company Elon runs`
- Crypto: `BTC-USD`, `ETH-USD`

## Running the Project

### Step 1 — Build the Docker image

```bash
docker build -t mas-equity-researcher .
```

This only needs to be done once, or after any code changes.

### Step 2 — Run the container

```bash
docker run --rm --env-file .env --name equity-run mas-equity-researcher
```

The `--name equity-run` flag names the container so you can reference it easily.
The `--rm` flag removes the container automatically after it exits.

> **Note:** Remove `--rm` if you want to copy the PDF after the run (see below).

### Step 3 — Wait for completion

The pipeline takes 3-5 minutes to complete. You will see each agent's progress printed live:

```
# Agent: Stock Research Input Specialist ...
# Agent: Financial Data Analyst ...
# Agent: Market Sentiment Analyst ...
# Agent: Senior Equity Research Analyst ...
# Agent: QA Analyst & Report Writer ...

reports/TSLA_research_2026-05-24.pdf
```

## Downloading the PDF Report

Since `--rm` removes the container on exit, run **without** `--rm` to keep the container available for copying:

```bash
# Run without --rm
docker run --env-file .env --name equity-run mas-equity-researcher

# After it finishes, copy the PDF to your current directory
docker cp equity-run:/app/reports/TSLA_research_2026-05-24.pdf .

# Open the report
open TSLA_research_2026-05-24.pdf        # Mac
xdg-open TSLA_research_2026-05-24.pdf   # Linux
```

Replace `TSLA_research_2026-05-24.pdf` with the actual filename printed at the end of the run.

### Finding the report filename

The filename follows the pattern:
```
reports/{TICKER}_research_{YYYY-MM-DD}.pdf
```

If you are unsure of the exact name, list all reports inside the container:

```bash
docker exec equity-run ls /app/reports/
```

### Clean up the container after copying

```bash
docker rm equity-run
```

---

## Changing the Stock

Edit the `STOCK` value in your `.env` file:

```bash
STOCK=AAPL
```

Then run the container again. No rebuild needed.

## Rate Limits

This project uses the Groq free tier which has the following limits:

| Limit | Value |
|---|---|
| Tokens per minute | 12,000 |
| Tokens per day | 100,000 |

Each full analysis run uses approximately 15,000-20,000 tokens, giving roughly **5 runs per day** on the free tier. The system includes automatic retry logic that waits between tasks to handle per-minute limits.

To remove daily limits, add credits at https://console.groq.com/settings/billing.

## Notes

- The Qdrant vector database is optional. If not running, the system falls back to generic sector-based risk factors automatically.
- The `.env` file is excluded from git via `.gitignore`. Never commit API keys to version control.
- Reports are saved inside the container at `/app/reports/` and must be copied out before the container is removed.
